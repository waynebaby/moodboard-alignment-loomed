降噪与识别

识别项目类型、审美词、共识与分歧、明确排斥方向。

方向确认

最多 3 个问题；只确认方向，不生成最终方案。

CK2

文字版方向稿

data.json + ck2-client.html + ck2-execution.html。

CK3

多视图情绪板

client / director / execution；亮暗切换，打印强制亮色。

→

执行方向资产

方向图、声音参考、Image Prompt、采买参考、设计约束。

Δ

增量修改回路

只改指定节点 / 图片 / 维度，不破坏未点名内容。
