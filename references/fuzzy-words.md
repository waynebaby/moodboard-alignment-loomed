# 模糊词翻译词典

原则：模糊词不是固定含义，而是可能性空间。先展开空间，再让用户定位。

| 客户原话 | 可能性空间 | 推荐追问 |
|---|---|---|
| 高大上 | A 极简克制 / B 奢华厚重 / C 未来科技 / D 人文质感 | 你说的高大上更接近哪一种？ |
| 有质感 | A 材质光泽 / B 胶片颗粒 / C 光影层次 / D 声音重量 | 质感主要来自材质、光影，还是画面颗粒？ |
| 干净 | A 大量留白 / B 色彩克制 / C 构图简洁 / D 信息层级清晰 | 是视觉留白的干净，还是信息表达的干净？ |
| 年轻化 | A 高饱和明快 / B 快节奏动感 / C 圆润柔软 / D 玩味不严肃 | 年轻化是更活泼，还是更轻、更不端着？ |
| 温暖 | A 日落暖金 / B 室内暖灯 / C 肤色亲近 / D 记忆感的暖 | 这个温暖偏真实生活，还是偏回忆滤镜？ |
| 冷 | A 蓝灰科技冷 / B 疏离情绪冷 / C 冬季自然冷 / D 金属质感冷 | 冷是情绪疏离，还是科技/材质上的冷？ |
| 电影感 | A 宽银幕构图 / B 浅景深 / C 胶片颗粒 / D 调色 LUT / E 叙事留白 | 电影感主要指画面语言，还是情绪余韵？ |
| 呼吸感 | A 留白多 / B 剪辑慢 / C 安静段落 / D 声音有间隙 | 呼吸感是画面留白，还是节奏放慢？ |
| 史诗感 | A 大景别宏大 / B 慢镜头仪式感 / C 深景深层次 / D 配乐推动 | 史诗感来自空间规模，还是音乐/节奏？ |
| 赛博朋克 | A 霓虹灯管 / B 雨夜街道 / C 全息投影 / D 改造人机械 / E 底层街区 | 要更商业霓虹，还是更脏、更底层？ |
| 高级 | A 克制留白 / B 材质精致 / C 低饱和配色 / D 秩序感强 | 高级是少即是多，还是贵重材质感？ |
| 松弛 | A 低密度信息 / B 慢节奏 / C 自然光 / D 非摆拍 | 松弛是生活化自然，还是高级留白？ |
| 有力量 | A 视觉冲击 / B 情绪重量 / C 节奏推进 / D 声音压迫 | 力量是外放冲击，还是安静但有重量？ |
| 不煽情 | A 克制表演 / B 少音乐推动 / C 少特写 / D 留白结尾 | 不煽情主要要控制音乐、表演还是剪辑？ |

使用规则：
- 不要把整张表一次性甩给用户。
- 每次只针对当前最关键的 1-3 个模糊词拆解。
- 如果用户已经用上下文说明含义，直接吸收，不重复追问。
- 抽象词确认后，要落到具体维度：色彩、构图、节奏、材质、声音。
