# HTML 视图模板

## 三个视图

同一份 data.json，渲染三种 HTML 视图：

### client（甲方版）

给：客户、甲方、品牌方
目标：30 秒确认方向是否正确

显示：
- 项目名 + 整体风格定位
- 关键词 tags
- 一句话定调
- 关键色板
- 节点：参考图 + 标题 + 情绪关键词（emotion.keywords / type）
- 节点简短一句话描述

不显示：
- 六维 details 展开（emotion / motion / color / composition / style / sound）
- Image Prompt
- 执行层注意
- 技术参数
- view / version / 数据数组名等元信息
- 风险提醒（内部用）

视觉：
- 页面更短、图更大、留白更多
- 节点卡：图占满宽度，标题和关键词在下方，一行内
- 没有折叠面板，只有简洁卡片

### director（汇报版）

给：创意总监、导演、制片人、项目负责人
目标：2 分钟判断方向对不对、能不能落地

显示：
- 项目名 + 整体风格定位
- 关键词 tags
- 一句话定调
- 关键色板
- 节点：参考图 + 标题
- 节点精简文字描述（emotion.type + description，color.description，style.description，composition.description）
- 执行层注意（如有）
- 风险提醒

不显示：
- Image Prompt
- 维度子字段展开（intensity、density、reverb 等）
- 完整的 keyword 列表（融入描述中）

视觉：
- 节点卡：左图右文，文字区域比 client 版多一层描述
- 有 summary-grid（已对齐共识 + 风险提醒）
- 无折叠面板，直接展示精简描述

### execution（执行版）

给：执行团队、创意人员、设计师、摄影师、调色师、声音设计师
目标：每个环节都能直接指导执行

显示：全部内容
- 六维 details 完整展开
- Image Prompt
- 执行层注意
- 风险提醒

视觉：现有完整版节点卡，左图右文 + 折叠面板

## 视图选择

通过 data.json 中的 `view` 字段控制，默认 `execution`。

render.py 接受 `--view client|director|execution` 参数，覆盖 data.json 中的 view 值。
